# Expo SDK 54

Este proyecto usa **Expo SDK 54** (React Native 0.81, React 19.1) porque es la
versión que soporta la app Expo Go publicada en la App Store. No subas el SDK sin
comprobar antes qué SDK soporta Expo Go, o dejará de abrirse en el móvil.

Consulta la documentación de esta versión: https://docs.expo.dev/versions/v54.0.0/
